# mother.nurture.d — Mother Nurtured website

Static website for **Mother Nurtured** (Dr. Kylie Riley, D.Ac., LMT · Reno, NV).

Pages: Home · About · Services · Watch · Guide · Contact. Booking links go to MassageBook.

## Deploy
Import this repo in Vercel → Framework preset: **Other** → no build command → Deploy.

## Edit
- Videos: `assets/video/` (looping, muted by default, tap speaker for sound)
- Images/logo: `assets/img/`
- Styles: `assets/css/style.css`
